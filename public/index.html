If the website is online but ESP32 is offline, inspect serial logs (115200), the hotspot's 2.4 GHz band, credentials, DEVICE_TOKEN and TLS certificate. If the hotspot uses CH 6 or CH 11 but pods are still fixed to CH 1, ESP-NOW messages can disappear. Change pod channels only through verified firmware/bench testing; channel 0 alone is not automatic synchronization. This web panel cannot retune hardware or disable LEDs/buzzer.
