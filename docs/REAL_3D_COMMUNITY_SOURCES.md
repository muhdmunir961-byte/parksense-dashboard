## Implementation notes
- Open **Overview** and select one of these seven real 3D source entries; the embedded 360° Sketchfab viewer loads only for the selected one.
- Panning/orbit/zoom are handled by Sketchfab. Internet access, third-party host availability and WebGL support are required.
- The model attribution is independent from the ESP32. Changing the car **never changes vehicle speed, warning thresholds, sensor distances or hardware behaviour**.
- The Dashboard remote threshold control appears on **Parking Assist**, protected by dashboard login and exact-origin POST authentication. The ESP32 must confirm the warning-threshold change; browser WebSocket remains read-only.
- The gallery excludes generic 3D stand-ins and sources not clearly available under an appropriate license. No claims of an exhaustive list of every car sold in Malaysia.
- If a source later changes or stops being available, the appropriate action is to replace/remove that entry (not scrape the protected files without the creator's consent).
